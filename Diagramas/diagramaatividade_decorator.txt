flowchart TD
    %% ============================================================
    %% DIAGRAMA DE ATIVIDADES - Padrão Decorator
    %% ============================================================
    %% Este diagrama mostra o fluxo de criação de uma reserva
    %% com serviços extras usando o Padrão Decorator.
    %% ============================================================

    Start((Início)) --> AcessarPagina[/Usuário acessa página de criação de reserva/]
    AcessarPagina --> ExibirFormulario[Exibir formulário com pacotes e serviços extras]

    ExibirFormulario --> SelecionarPacote[Usuário seleciona tipo de quarto e pacote]
    SelecionarPacote --> MarcarDecorators{Usuário marca serviços extras?}

    MarcarDecorators -->|Não| CriarReservaSemDecorator
    MarcarDecorators -->|Sim| CriarReservaComDecorator

    %% ============================================================
    %% FLUXO SEM DECORATOR (Caminho Original)
    %% ============================================================
    CriarReservaSemDecorator[Controller.Criar]
    CriarReservaSemDecorator --> FacadeSemDecorator[Facade.CriarReservaComPacote]
    FacadeSemDecorator --> BuilderSem[Builder cria pacote base]
    BuilderSem --> GerenciadorSem[Gerenciador cria reserva]
    GerenciadorSem --> SalvarSem[Salvar reserva no repositório]
    SalvarSem --> RedirecionarDetalhes[/Redirecionar para página de detalhes/]

    %% ============================================================
    %% FLUXO COM DECORATOR (Caminho com Padrão Decorator)
    %% ============================================================
    CriarReservaComDecorator[Controller.CriarComDecorators]
    CriarReservaComDecorator --> ReceberLista[Receber lista de decorators selecionados]
    ReceberLista --> ChamarFacade[Chamar Facade.CriarReservaComPacoteEDecorators]

    ChamarFacade --> ObterQuarto[Obter protótipo de quarto via Prototype]
    ObterQuarto --> CriarBuilder[Criar Builder para tipo de pacote]
    CriarBuilder --> Director[HotelDirector constrói pacote base]
    Director --> ObterPacoteBase[Obter PacoteHospedagem base]

    %% ============================================================
    %% APLICAÇÃO DOS DECORATORS
    %% ============================================================
    ObterPacoteBase --> IterarDecorators[Iterar sobre lista de decorators]

    IterarDecorators --> VerificarDecorator{Há mais decorators?}
    VerificarDecorator -->|Sim| CriarDecoratorInstancia[Factory Method: Criar instância do decorator]
    CriarDecoratorInstancia --> AplicarDecorator[Decorator.AdicionarServicoExtra]
    AplicarDecorator --> AtualizarPacote[Decorator adiciona serviço ao pacote]
    AtualizarPacote --> AtualizarDescricao[Decorator atualiza descrição do pacote]
    AtualizarDescricao --> VerificarDecorator

    VerificarDecorator -->|Não| CalcularValor[Calcular valor total com decorators]

    %% ============================================================
    %% CÁLCULO DO VALOR TOTAL
    %% ============================================================
    CalcularValor --> VerificarDecoratorAplicado{Houve decorators aplicados?}
    VerificarDecoratorAplicado -->|Sim| UsarCalculoDecorator[Usar CalcularValorTotalComDecorators]
    VerificarDecoratorAplicado -->|Não| UsarCalculoPadrao[Usar CalcularValorTotal padrão]

    UsarCalculoDecorator --> VerificarDisponibilidade[Verificar disponibilidade do quarto]
    UsarCalculoPadrao --> VerificarDisponibilidade

    VerificarDisponibilidade --> Disponivel{Quarto disponível?}
    Disponivel -->|Não| RetornarNull[Retornar null - erro]
    Disponivel -->|Sim| CriarReservaObj[Criar objeto Reserva]

    RetornarNull --> ExibirErro[/Exibir erro de indisponibilidade/]
    ExibirErro --> Fim((Fim))

    CriarReservaObj --> AtualizarValorTotal[Atualizar ValorTotal com cálculo dos decorators]
    AtualizarValorTotal --> ChamarGerenciador[Chamar Gerenciador.CriarReservaWeb]
    ChamarGerenciador --> SalvarRepositorio[Salvar reserva no repositório]
    SalvarRepositorio --> RetornarReserva[Retornar Reserva criada]

    RetornarReserva --> MontarMensagem[Controller monta mensagem de sucesso]
    MontarMensagem --> IncluirDecoratorsMsg{Incluir decorators na mensagem?}
    IncluirDecoratorsMsg -->|Sim| AdicionarLista[Adicionar lista de serviços extras]
    IncluirDecoratorsMsg -->|Não| ApenasPacote[Apenas nome do pacote]
    AdicionarLista --> Redirecionar
    ApenasPacote --> Redirecionar

    Redirecionar[RedirectToAction Detalhes com ID da reserva]
    Redirecionar --> RedirecionarDetalhes

    class MarcarDecorator,VerificarDecorator,VerificarDecoratorAplicado,Disponivel,IncluirDecoratorsMsg decisao

    class CriarReservaSemDecorator,RetornarNull,ExibirErro processo
